# Agent brand marks

Bundled locally so the composer never depends on a third-party asset request.

- Claude, Codex and OpenCode: SVG marks from [Lobe Icons](https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons) (MIT). Brand marks belong to their respective owners.
- Pi: the `pi-logo-mark` SVG published at [pi.dev](https://pi.dev/).

All four marks render through an alpha mask and inherit the UI foreground. The
original SVG assets retain their published paths and colors; the interface uses
one consistent monochrome treatment in both themes.
Pi and OpenCode have their view boxes cropped to the mark's bounds so their
visible height and centering match the other icons.
