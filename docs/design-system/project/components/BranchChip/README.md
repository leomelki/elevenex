# BranchChip

A task's branch, where you need it: in the task header (compact) and in the task line of a new session (with what it started from). Click the name to rename it; the copy button copies it, and its icon springs to a check for a moment.

**Provide:** `name`, optional `base` (shown as “from main”), `compact` (header: name and copy only).

- Do show the branch in the header and the task line, never in sidebar rows.
- Do say so when renaming after the first push: the remote branch is renamed too.
