# FileChip

A file a turn changed, under its answer: the file name first, its folder muted, the line counts. Clicking it opens the file in the Changes view. Chips pop in one after another when the turn finishes; added files show a plus.

**Provide:** `path`, `add`, `del`, optional `status` (`M` · `A` · `D`), `index` (for the stagger).

- Do keep at most three per turn, then “+N”; the Changes view has the full list.
