# IconButton

A 28px square action holding a single icon, muted until hovered; `active` makes it a toggle (pressed = `accent` on `accent-soft`).

**Provide:** `icon`, `label` (required: becomes the accessible name and tooltip), optional `active` (boolean, for toggles), `size` (`sm` = 24px).

- Do use for toolbars: toggle sidebar, toggle side panel, attach, mention.
- Don't use for anything a person must discover; give it a text `Button`.
