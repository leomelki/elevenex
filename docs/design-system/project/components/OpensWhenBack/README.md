# OpensWhenBack

Opening something this window never loaded, while its machine is out of reach. It says so where you clicked: no error toast, no spinner that never ends.

- "**Opens when dev-box is back**", then why: "This session wasn't loaded in this window yet, and dev-box is out of reach." (also `changes`, `file`, `terminal`, `browser`).
- **Try now** opens the island's panel, and a back button returns to what you were on.
- What the window already loaded opens as usual, marked "as of 14:02". Only what it never had shows this.
- `compact` for the side panel.

**Provide:** `machine`, `what`, `compact`, `onTry`, `onBack`, `backLabel`.
