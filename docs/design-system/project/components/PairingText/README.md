# PairingText

On the computer that hosts (Settings › Pairing): a long pairing text to copy and paste on the other computer. It works like a key.

**Provide:** `text`, `copied`, `onCopy`.

- Do say it lets the other computer use this one.
- Do pair once: after that, the other computer opens this one any time without asking again, until either side removes it. While it's connected, this computer's island says so, with Disconnect.
