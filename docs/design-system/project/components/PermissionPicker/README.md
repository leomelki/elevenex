# PermissionPicker

How much the agent may do without asking, as a quiet shield chip: **Ask first** (approve every edit and command), **Auto-edit** (file edits apply, commands still ask), **Full auto** (nothing asks; the task's sandbox is the limit).

**Provide:** `value` (`ask` · `edits` · `auto`), `open`.

- Do remember the choice per task, and default new tasks to the project's setting.
- Do surface approvals as a *needs you* status when the agent is waiting on one.
- Don't show it in Plan mode, where nothing is edited.
