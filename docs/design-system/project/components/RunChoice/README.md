# RunChoice

**Provide:** `value` (`local`, `ssh`, `peer`), `onChange(id)`.

- Do keep This Mac first and recommended: it needs no setup.
- Do follow “A server” with `HostField`, then `HostKeyCheck` and the install steps (`GettingReady`); follow “Another computer” with `PairPaste`.
