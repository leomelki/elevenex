# StatusBadge

A pill with the status glyph and its word, on the status's soft ground; used in headers and lists where the state needs a word.

**Provide:** `status`, optional `label` to replace the default word (“Needs you” → “Needs approval”).

- Do use the default words: Running, Needs you, Review, Done, Failed, Queued.
- Don't use badges inside sidebar rows; rows carry the glyph alone.
