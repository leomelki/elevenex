# Switch

An on/off control for settings that apply at once: fast mode, an MCP server. Off is a `line-strong` track; on is `accent`.

**Provide:** `on`, `label` (required: the accessible name), optional `onChange(on)`.

- Do place it at the end of the row it controls, with the row's text as its label.
- Don't use it for choices that need confirming; use a button.
